# PRINTFAS App Icons

This directory should contain the PWA icon files:

- `icon-192x192.png` - 192x192 pixel PNG icon
- `icon-512x512.png` - 512x512 pixel PNG icon

## Instructions

Replace these placeholder files with your actual PRINTFAS branded icons:

1. Create a square logo with your brand colors
2. Export as PNG in both 192x192 and 512x512 sizes
3. Save as `icon-192x192.png` and `icon-512x512.png`

For the placeholder, you can use any square image with a blue background (#2563eb) and white text "PF" for testing purposes.
